# Security

Faceless QC Lite runs 100% locally: no network calls, no telemetry, no accounts.
It reads only the video file you pass it and writes nothing unless you redirect output.

Found a problem? Open an issue titled `Security:` with the details, or, for anything sensitive, say so in the issue and we will arrange a private channel before you post details.

Note: Lite parses video through your local FFmpeg — keep FFmpeg updated from ffmpeg.org or your package manager.
